# Security Lab Rules

1. All testing is performed only against systems owned
   and intentionally configured for this laboratory.

2. The lab must remain isolated from the physical/home
   network.

3. No unauthorized systems may be scanned.

4. No real passwords, private keys, tokens or personal
   credentials are stored in the repository.

5. Sensitive Wazuh credentials must never be committed.

6. Fake data is used for security testing.

7. Screenshots must be reviewed before being uploaded.

8. Snapshots should be created before major experiments.

9. Offensive-security techniques are restricted to the
   isolated laboratory environment.

10. Evidence and findings must be documented accurately
    without inventing results.
